# Пепельные земли — игра по сети

Комната целиком живёт на сервере (`server.js`): он запускает игру и считает ходы. Телефоны игроков — только экраны.
Свернул игру, закрыл вкладку, пропал интернет — партия не ломается. Если игрок пропал на своём ходу, через ~75 секунд
сервер сам пропускает его ход. Вернулся (зашёл по той же ссылке) — продолжает со своим героем.

## Что должно лежать в репозитории (корень)
`index.html`, `server.js`, `package.json`, `README.md`. Сервер читает игру из `index.html` рядом с собой.

## Запуск сервера
```
node server.js              # порт 8080, режим разработки
PORT=3000 BOT_TOKEN=... ORIGIN=https://ВАШ.github.io node server.js
```
Render: New → Web Service → репозиторий → Build `npm install`, Start `node server.js`, Free.
Проверка: адрес сервера в браузере должен вернуть `{"ok":true,"rooms":0,"v":2}` (v:2 — новая версия).

## Игра
Создатель: открыть игру → вписать адрес сервера → «Создать комнату» → «Скопировать ссылку» → отправить друзьям.
Друзья открывают ссылку и создают героев. Создатель выбирает историю, цель и сложность и жмёт «Начать приключение».
Вверху экрана — код комнаты, чей ход и кнопка «👥» со списком участников и пингом.

## Telegram Mini App
BotFather → /newapp → адрес index.html на GitHub Pages. В Render добавить переменную `BOT_TOKEN` (токен бота).
Ссылка-приглашение: `https://t.me/ИМЯ_БОТА/ИМЯ_ПРИЛОЖЕНИЯ?startapp=КОД`.
Проверка подписи Telegram написана по документации, но с настоящим ботом не проверялась.

## Ограничения
- Комнаты хранятся в памяти сервера. Бесплатный Render засыпает после 15 минут без запросов, а при перезапуске
  комнаты пропадают (игроки увидят «комната закрыта» и создадут новую).
- В комнате до 8 подключений, героев — до 5.
