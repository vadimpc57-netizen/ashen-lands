# Пепельные земли — мультиплеер

Как это устроено: игра считается в браузере **создателя комнаты** (хост). Остальные игроки подключаются по коду,
каждый создаёт своего героя и ходит со своего телефона. `server.js` — только почтальон: пересылает действия
участников хосту и состояние игры — участникам. Зависимостей нет, нужен Node 18+.

## 1. Запустить сервер
```
node server.js              # порт 8080, режим разработки
PORT=3000 BOT_TOKEN=... ORIGIN=https://ВАШ.github.io node server.js
```
Подойдёт любой хостинг с Node (Render, Railway, Fly.io, свой VPS). Нужен HTTPS-адрес (на Render/Railway он выдаётся сам).
Проверка: открыть адрес сервера — должно вернуться `{"ok":true,...}`.

## 2. Выложить игру
1. В `index.html` найти строку `const PZ_DEFAULT_SRV = '';` и вписать адрес сервера (или собрать файл так: `python3 build_index.py https://ваш-сервер`).
2. Загрузить `index.html` в репозиторий и включить GitHub Pages.

## 3. Играть
Создатель открывает игру → «🏰 Создать комнату» → «📋 Скопировать ссылку» → отправляет друзьям. Друзья открывают ссылку
(или вводят код), создают героев. Создатель жмёт «Начать приключение». Чей ход — у того активны кнопки, остальным
показывается «⏳ ходит …». Если игрок пропал, создатель может нажать «⏭ пропустить». Если создатель обновил страницу —
в лобби появится «↩️ Продолжить свою комнату».

## 4. Telegram Mini App
1. В @BotFather: создать бота, затем `/newapp` (или кнопка меню) → адрес `index.html` на GitHub Pages.
2. Передать серверу `BOT_TOKEN` — тогда личность игрока берётся из подписи Telegram (подделать чужой id нельзя), а не из случайного токена.
3. Ссылка-приглашение вида `https://t.me/ИМЯ_БОТА/ИМЯ_ПРИЛОЖЕНИЯ?startapp=КОД` сама откроет игру и подключит к комнате.
   Для обычных ссылок работает `?room=КОД`.

Проверка подписи Telegram написана по документации, но с настоящим ботом не проверялась — проверьте при первом запуске.

## Ограничения первой версии
- Состояние живёт в браузере хоста: если хост закрыл игру надолго, комната останавливается (при возврате — «Продолжить»).
- Участники видят анимации хоста урезанно (баннеры и результат хода приходят, бросок кубика — только результатом).
- Комнаты хранятся в памяти сервера: перезапуск сервера закрывает комнаты, хост может восстановить свою кнопкой «Продолжить».
